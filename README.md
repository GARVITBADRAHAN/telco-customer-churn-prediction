# Telco Customer Churn Prediction

## Project Overview
This project uses machine learning to identify telecom customers who are likely to discontinue their service.

## Business Objective
Predict customer churn, identify the factors associated with churn, and help the business prioritize customer retention campaigns.

## Dataset
- Source: [Kaggle — Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
- Rows: 7,043
- Columns: 21
- Target variable: `Churn`

## Project Workflow
1. Business requirements and data acquisition
2. Exploratory data analysis (EDA)
3. Data quality assessment
4. Feature engineering
5. Baseline model development
6. Model evaluation and explainability
7. API and dashboard deployment

## Technology Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
